MODEL AND DISPLAY

STATE — The register contains the 91 hydrogen basis states with n ≤ 6. Norm, energy, and autocorrelation come from their coefficients.

SHADOW — The same coefficients appear as q = √2 Re c and p = √2 Im c. This is another view of the quantum state.

FIELD — The renderer samples ψ on the selected 3D grid and ray-marches it. Grid size and quality change the picture, not the state.

MASKS — Mute and solo affect the reconstruction only. The state keeps every coefficient, and the status shows how much norm is visible.

VIEW AND STATE — Camera, slice, and clip controls change the view. State transforms change |ψ⟩.
