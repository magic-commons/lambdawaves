## §1 · THE TEXEL PRESENTER (`lab/field.js`, `RENDER_WGSL` :289–531)

### 1.0 What the shader takes in
- Textures: `psiTex` (the volume, `.rg` only) and `refTex` (the Δρ reference, `.rg`) both rgba16float 3-D (field.js:1040–1041), sampler, `stats` (u32 bitcast f32: `stats[0]` = max ρ of ψ, `stats[1]` = max ρ of ref), `pal` = 256×vec4 palette LUT (field.js:303–312, upload :861–867). (KNOWN)
- The uniform `View` is 11 vec4s (`viewBuf` = 11 × 16 B, field.js:946; struct :291–302, written :1095–1117). p0 = (view id, exposure, softness, ray-jitter seed); p1 = slice mode/axis/pos/thick; p2 = (hue, invert, palette on, dither LSB); p3 = (style, iso, grain, knee); p4 = bow (k, on); p6 = slice normal + finish; p5 = stage background + gamma. **Every lane of every vec4 is assigned** (KNOWN: reading :1095–1115) — a new scalar parameter costs a 12th vec4 (a `viewBuf` + struct change), a new *view id* costs nothing in the uniform (it rides p0.x).
- The march: `for (var i = 0u; i < 512u; i++)` (field.js:396), one trilinear `textureSampleLevel` of `psiTex` per step (:399–400), +1 of `refTex` in the Δρ branch (:436), +6 `rhoAt` samples per `litAt` (:336–344) for SOLID / SIGNED / SHELL / any non-"lit" finish. Steps = `min(mat.steps||160, stepCap)` (field.js:1099). Opacity `a = 1 − exp(−wEff·sigma·stepN·4)` with `sigma = exposure·24` (:387, :507). (KNOWN)
- The output goes through `pow(…, 1/gamma)` then Bayer-8 dither (:521–530). Palette-OFF colours are the old built-ins. (KNOWN)

### 1.3 Specialisation and lock counts

- **The 120 locked style values** (MEASURED from the script's structure): `styles()` at tools/perf/digest-lock.mjs:172–190 = every VIEW × every STYLE at 96³ on `1s+2pz` (**6 × 8 = 48**, :174–176) + nine flag rows (`palette-on, palette-off, invert, finish-glass, finish-matte, dither, bow, slice-clip, slice-slab`, :177–182) each on the eight (view, style) pairs of `FV` (:183: `[0,0] [1,0] [2,0] [4,0] [1,1] [0,3] [5,6] [3,7]`) = **72**. 48 + 72 = **120** (the file header :35–37 states it the same way). ### 1.4 What a NEW kind needs (Φ, an equalizer's signed ρ′, a per-site density)
The presenter's contract is the texel only: `.rg` of rgba16float (field.js:327, :400, :436). A new kind is cheap exactly when it reuses one of the six read-laws.
- **Reuse (0 presenter lines, lock untouched):** put the new quantity in `.r` as a signed value and let the producer say `view: 'real'`. The molecule road already does this: `kind: 'signed'` → `molKind 3` (field.js:1562) → `view 'real'` (chemview.js:476, statesview.js:300). A **per-site density** is just kind 0 with a projected D matrix (a `density` product, zero new lines in the presenter or the session; the producer builds the matrix); an **equalizer ρ′** (signed) is kind 3 / `real`; a **signed potential Φ on a grid** is `real` too. Caveat for Φ and any long-range signed field: view 2's transfer is `w = (v/ampMax)^(2·soft)` — opacity grows as the SQUARE of the signed value (:421–422), tuned for lobes; a 1/r tail will fill the box, so EXPOSURE/KNEE/SOFT must absorb it, or the branch needs its own transfer (next bullet).
- **New VIEW branch (presenter lines + the lock):** a new id needs `VIEW`/`VIEW_NAMES` (field.js:18–19), one `else if (mode == 6u)` placed BEFORE the Δρ `else` (:435), a UI option (material.js:25), a sentence in `VIEW_SAY` (badges.js:46), the `V` key cycle list (shell/keys.js:79), and a palette law. ~8–15 WGSL lines (S). **Lock consequence (KNOWN, digest-lock.mjs:174–175, :264–265):** `styles()` iterates `fm.VIEW_NAMES`, so a 7th name emits 8 new keys (`view6/style…`) absent from the fixture; the compare takes the UNION of keys (:265), so `--check` goes RED on key-set difference alone. Remedies: a tools/ edit teaching `styles()` to skip keys the fixture does not hold (the script already does this for *states* at :255–262), or keep the id out of `VIEW_NAMES`. Any edit to `RENDER_WGSL` text also owes a 0/0 run (MAP-CODEBASE fact 8: the presenter is inside the lock). The 24 specialised copies re-derive from the edited source automatically (`once(...)` anchors, :551–558) — but an anchor drift throws, "generic forever".
- **New KERNEL (producer) lines:** a Φ cloud needs a producer that fills a texture: a new `molWgsl` kind (`MP.kind` 4, field.js:170) is outside the lock for molecules (STATES/kind 3 unlocked) but inside the file the lock reads; a new `COMPUTE_WGSL` space (:85–127) is hydrogen path = locked wholesale (432 values) → a 0/0 run owed.
- **The meaning check (C7) does not exist today.** There is no assertion between producer meaning and VIEW anywhere: the contract is the comment at field.js:143–163 (density → (√ρ,0): "phase reads atan2(0,√ρ) = 0 — a flat phase"). The stand-downs that do exist are separate hand-written lists: `overlayDomain` (rack.js:478: space 'x' ∧ `hydrogenTheorems` ∧ ¬Sturmian ∧ ¬MOLECULES) gates VORTEX/PARTICLES/KEPLER (rack.js:479–498); `hydroReader()` (rack.js:738–746) gates WIGNER/RADIATION; `moleculeMode()` folds SPECTRUM. Nothing disables the OBSERVABLE seg when a molecule owns the field (grep of `viewSeg` outside material.js: only the molecule view-road, molecules.js:41–42, bow, persist, keys). (KNOWN)
