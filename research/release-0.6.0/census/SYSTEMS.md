## 0 · How to read the catalogue (five facts the tables rest on)

* **A "system" in this tree is a HAMILTONIAN-in-force over the 91 labels, or a molecule, or a stand-alone window with its own register.** Exactly five Hamiltonians exist: `hydrogen` (+ its Z scaling), `qho`, `well`, `cornell`, `atom` (`lab/hamiltonian.js:26, 38, 55, 74, 144`; KNOWN). * **Data shapes** (the column "SHAPE" below): **K0/K1/K2/K3/K6** = a *Mode record* in COMPUTE_WGSL, kernel space N (`lab/field.js:27–140`, branches at `:85` (0,5), `:90` (4), `:95` (3), `:107` (6), `:113` (2), else 1; 112-byte record, `MODE_BYTES` `:25`, `MAX_MODES = 320` `:24`; KNOWN). **MOL-T** = shells + coefficients through `molWgsl` density tile, caps 16/40/64/128 (`:748`; KNOWN). **MOL-O** = the same through `ORB_WGSL` for an orbital past 64 AO (`:749` `MOL_ORB_FROM`; KNOWN). **WK** = a CPU/worker model whose result is drawn on a canvas/lines with no texel. **CPU** = readout only.
* **The kernel's only vocabulary is "radial function × spherical harmonic" (central potential), per mode** (the `D` Legendre polynomial of 6 coefficients, `ipow(st, am)`, `field.js:83–84`). Anything non-central (a cube, a double well, a lattice, two particles, spin) cannot be a Mode record except through the AXIAL gas's trick of expanding in l ≤ 15, m = 0 (`lab/gas.js:1–17`, `LMAX = 15, NRMAX = 16`, KNOWN → 256 modes).
* **STATUS badges are file-header comments, not UI objects.** The app's live badges are two plus two warnings: `STATE · EVOLUTION · SHADOW` (exact) and `FIELD` (numerical) (`lab/badges.js:21–22`; KNOWN). Where I write "STATUS" below it is the header line in the model file. Files with **no** STATUS line at all (MEASURED by `grep -n STATUS lab/*.js`): `gas.js, md.js, rhf-molecule.js, molecules.js, library.js, chemview.js, statesview.js, orbitalsview.js, molecular-register.js, molecular-session.js, hamiltonian.js, spectrum.js`.
* **THE LOCK** = 13 states (`tools/perf/digest-lock.mjs:137–155`; KNOWN): `1s+2pz, rydberg, h91, box, gas, momentum, oscillator, quarkonium, sturmian, chem (H2O), chemC6H6, chemLys, chemLysHomo`. So the lock covers kernel spaces **0, 1, 2, 3, 6** and molecular tiers **16 (H2O 7 AO), 40 (benzene 36 AO), 64 (lysine, density + HOMO)**. It covers **nothing** in: space 4/5; tile 128; ORB_WGSL (C60 route); ATOM (space 6, but Ne's table is not locked), Z ≠ 1, STARK, ZEEMAN, any drive/kick/run, TD-CIS, Wigner, radiation.
