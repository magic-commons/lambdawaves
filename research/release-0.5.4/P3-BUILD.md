## 1 · `contract()` and `GEOMETRY_CLASSES` — the generator writes the fields, never the app

`tools/orbital-library.mjs:401` holds the four classes as `[name, regexp]` pairs matched against the record's own `row.source`
(`stem.geometrySource`), and `contract(source, oracle, energy)` (`:403-406`) returns the three members a row carries:

    oracle:   { what, delta }                   — the record's own PySCF oracle line and its measured δ (≤ 1e-8 Eh)
    geometry: one of experimental · optimised-here · computed-reference · draft
    status:   { energy: 'MEASURED' | 'IMPORTED', geometry: <the class>, derivatives: 'UNKNOWN' }

| class | pattern | rows |
|---|---|---|
| `experimental` | `^(NIST )?CCCBDB experimental ` | 2 — C6H6, TiCl4 |
| `optimised-here` | `^optimised here, UNVERIFIED` | 26 |
| `computed-reference` | `^wwPDB Chemical Component Dictionary ` or `^https://raw.githubusercontent.com/psi4/` | 9 (5 + 4) |
| `draft` | `^DRAFT GEOMETRY` | 1 — C60 |

An unmatched source THROWS (`:405`) — never a silent UNKNOWN. The app writes MEASURED (a solve checked against PySCF, `:387`) or IMPORTED
(PySCF's own number carried in, δ = 0 by construction — C60, `:496`); never CERTIFIED, which only a pilot-signed member may carry (the
header at `:394-396` says so). `derivatives` are UNKNOWN on every row: nothing in the tree computes them.
