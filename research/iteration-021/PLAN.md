## THE DREAM, AND THE PATH (Josh: "if you were given the dream job of making your dream architecture… how would you write it/organize it?")
The dream is not a new folder tree — it is five CONTRACTS the code already half-keeps, made whole. Moving folders (physics/, engine/) rewrites the sw paths, the map and the laws for no runtime gain; the contracts are what a reader, a builder and a kit day need:
1. ONE STORE. `records.js` (or `store.js`) is the registry of every stored key `{ key, scope, version, migrate, forget, owner }`; every store is `createRecord(row)`; STATE-SCOPES.md is GENERATED from it; no module touches localStorage; FORGET reads the `forget` flag; the settings blob loses its carry list; WORKSPACE (every window placement, the folds) is one record that is also a project part. Opened through one transactional `openProject(parts, { rollback })` — history, session, FOLDERS, links and quick LOAD all on it.
2. ONE ACTION REGISTRY. `actions.js`: `{ id, label, group, kind: fire|toggle|hold|set, get?, run(args), keys?, surface?, gesture?, undo }`; the key table, the menus (trees of ids), the CSB's seats, the verb table, the facade, MIDI and the MAPPING tab all READ it; toggles expose `get()` so menus draw ✓ and the bar lights; one wrapper names every history row; Escape is a stack in the same module. Nothing is reached by label or `.click()`.
3. ONE TIME. `clock.js` keeps one position (t in a.u., the beat through RATE/BPM), one `seek`, one `step`, a mode WALL | LOCKED | RECORD that drives physics, modulation and rotation together; it is the only writer of t.
4. ONE MODE. `hydrogen | molecules` as a value with `availability(control) → { on, why }`; windows declare their mode at `device({ mode })`; field decisions read `molSession.selected`, never the UI switch.
5. ONE KIT. The app passes options and doors and never forks a kit seam (`mod-port` → `installModulation`; the icon table through `registerGlyphs`; one audio context); the kit ships as 1.5.5 and every later λWAVES edit is an additive door at `1.5.6-alpha.N`; `adopt.mjs` is the only writer of `lab/mir`.
Each window is `install(app) → { id, eyebrow, build, tick?, digest?, save?, restore?, targets?, mode, glyph }` and boot is a list of installs; the loop runs registered ticks. The path is bounded rows under THE LOCK and the formats, below; the cuts to folders come last or never.
