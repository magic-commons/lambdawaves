**What causes it.** The large-molecule work did not cause it, and no window leaves a scale behind. The march box (`lab/field.js`: `[−half, half]³`, `rp`/`rpL`), hydrogen's `domainFor(n) = 2n²+3n+2` and the rack's AUTO expression all match the pre-library tree (`d0a8cf3~1`). The only code that writes `domain.half` is `applyRebuild` (rack.js :324). CENTRAL, SEPARABLE and the ATOMS window do not write it.
The clipping is in the **ATOM system**. Its law has been the same since `d3df5b4` (PRE-ALPHA-2 FREEZE): `lab/hamiltonian.js :153` `domainFor: () => atomState().half`, with `half = atomDomainFor(Z)`. That half is the reach of the **occupied** shells. It does not change with what is populated. The same freeze commit gave every (n ≤ 7, l) a **virtual** row (°). A virtual row is the frozen field's near-hydrogenic orbital, about n² across, so it was drawn inside the atom's own small box. Even H's first excited shell, 2p°, clips in ±7. This is "atom mode is absurd".
There is also a second, smaller path that affects every system, hydrogen included. `touchState` (`lab/shell/controller.js :268`) rebuilt the box only when the unfiltered `reg.nmax()` moved. `applyRebuild` sizes the box by `reg.nmax(1e-3)`. So a label first painted below 1e-3 of the norm and then raised kept the small box: 1s + 3d₀ at 0.02 → 0.7 stayed at ±7 (see below). This is "hydrogen is less absurd".

**The law, before → after.**
- ATOM: `half = atomDomainFor(Z)` → `atomHalf(nmax, reg)`, which is the larger of the atom's own size and the edge `rTab` of every row the register draws. A row counts when it holds at least 1e-3 of the norm, the same filter as `reg.nmax(1e-3)`. `rTab` is the row's own 99.9 % × 1.25 radius, where its table ends, so nothing a label draws reaches past a face. Occupied labels keep the atom's box, so LOAD VALENCE and Fe 1s/2p/3d look the same as before. When there is no `reg`, it falls back to CENTRAL's law (every row with n ≤ nmax).
- rack.js `applyRebuild`: `HH.domainFor(reg.nmax(1e-3))` → `HH.domainFor(reg.nmax(1e-3), reg)`. The other systems ignore the second argument.
- controller.js `touchState`: the REBUILD key `reg.nmax()` → `reg.nmax() + '|' + domainFor(reg.nmax(1e-3), reg)`. The box is now rebuilt whenever the box the rebuild would choose moves.
