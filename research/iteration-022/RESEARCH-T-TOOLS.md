(a) Figma: `claude plugin install figma@claude-plugins-official` bundles the MCP + Agent Skills; remote `https://mcp.figma.com/mcp`; desktop `127.0.0.1:3845/mcp` needs a Dev/Full seat; read side components/variables/layout/Code Connect; write side (beta) sends live web UIs to the canvas as editable layers — so a design can be created from code, only inside a paid account. https://help.figma.com/hc/en-us/articles/39888612464151-Claude-Code-and-Figma-Set-up-the-MCP-server · https://www.idlen.io/news/figma-canvas-agents-mcp-server-skills-claude-codex-cursor/ · https://github.com/markj81/figma-mcp-skills
(b) "CSS godmode": no CSS tool of that name. The "godmode" skills are NousResearch's jailbreak skill (do not install; https://www.skillsdirectory.com/skills/nousresearch-godmode), a direct-response style skill, a workflow plugin. The browser "God Mode" is `document.designMode = "on"` (edits text). Live-CSS extensions: Amino, Stylus, Inspecta, CSS Scan. Best reading: live CSS editing in DevTools, which the suites' CDP helper / Playwright `browser_evaluate` already give an agent.
(c) UI crafting practice: frontend-design as the baseline and a screenshot-and-iterate loop as the highest-leverage addition ("without a visual feedback loop the model cannot grade its own work"); Playwright returns an accessibility tree beside pixels; shadcn/Magic UI MCPs assume React + Tailwind. https://composio.dev/content/top-design-skills · https://qaskills.sh/blog/claude-code-screenshot-frontend-verification-mcp · https://ruoqijin.com/blog/frontend-design-skills-ai-agents · https://www.aidesigner.ai/blog/claude-code-frontend-design
(d) Relief depth: neumorphism recipes quote 6–9 px offsets and 12–18 px blur for CARDS (https://csstools.io/blog/css-neumorphism-guide · https://superdesign.dev/styles/neumorphism); dark mode wants a grey highlight, not white; shadow-only state changes fail WCAG 1.4.11 without a focus cue (https://www.setproduct.com/blog/neumorphism-design-guide); Comeau: one light, colour-matched layered shadows beat one big soft one (https://www.joshwcomeau.com/css/designing-shadows/). Inference: for small controls the card recipe scaled down gives ≈ 1 px offset with 1–3 px blur — what FROST already does; SOLID's 2/6 at 70 % white and MORPH's 14 px shine are the outliers Josh sees.
