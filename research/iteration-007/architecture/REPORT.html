Candidate 1

A target is declared once, by the window that owns its dial

rank 1Strongin-process

Problem
One target is spread over four places: the defs row, the modSeats row, three members on the window, and the setKnob echo. The table is installed once, so the ORBITAL dial's range, which depends on the molecule, cannot be said at all.
Solution
Each window declares target(id, spec) beside the dial. The mod port installs it, re-registers it with a new range, stamps it and derives the seat.
Wins
  • leverage: one row gives route, lane and save
  • locality: ORBITAL's range change stays in MOLECULES
  • two registration doors become one
  • interface shrinks: knobs, setKappa and setSpeed go
  • a rebuilt dial keeps its stamp

Design it twice · six parallel designers, three constraints each

Candidate 1: the target seam

The problem space

The constraints. Saved ids stay stable (chem.kick, chem.speed, reg.*). The app literal is never extended. lab/mir is never edited. Each window seat keeps its rack-deps hinge at 25 or below. The windows are built (rack.js:695, :709) before the seam installs (:737), so a declaration made at creation must be queued. The kit has two facts that make it possible: an integer map, and hot re-registration that keeps the base and the routes. Dependency: in-process.

// illustrative only: what a window must be able to say
target('chem.orbital', { map: 'integer', min: 1, max: sol.nAO, get: () => orbital, set: (v) => { orbital = v; pushMatrix(); }, dial: () => orbKnob });
A1 · minimise the interface

One verb, re-declare to change

target(id, spec) → descriptor
spec = registry spec + dial(), seat, echo
  • A window knows one call. The shell keeps install and gains seats(data).
  • Re-declaring is the only gesture, both for a new range and for a rebuilt dial.
  • The facade door becomes register = mod.target.
  • Thin: about 14 spec fields, and a seat path that knows instruments.chem.
A2 · maximise flexibility

declare() with a live handle

declare(spec | control() | spec[]) → Handle
Handle { refresh, redial, retire, live }
spec.range(), present(), flash: 'step'
  • It accepts the kit's control() output, so the plain spec and control() are two real adapters.
  • Live ranges come through range(); present() sends routes dormant.
  • flash: 'step' caps how fast an integer target can strobe.
  • Thin: a lifecycle (present, retire) that every reader must follow.
A3 · the common caller

A one-liner bound to the record

api.target(id, knob, { min, max, get, set })
  → { rebind(knob, [lo, hi]), drop() }
group = root · seat = leaf · set gets a clamped v
  • The default case is one line. A declarer('chem') binds the record, so the seat comes from the id.
  • The seam echoes the dial, so set just stores.
  • It found that the port's idOf cache is built once (mod-port.js:66).
  • Thin: forgetting rebind after replaceWith leaves the dial dead without a word.

Recommendation · a hybrid, mostly A1

Take A1's single verb, target(id, spec), where calling it again is the hot re-registration. That makes a new range and a rebuilt dial the same gesture, and leaves the window no handle to forget. Add A3's two defaults: a declarer('chem') binds the record, so seat defaults to the id's leaf and the path never leaks; and the seam does the echo, so set only stores. From A2, take only the per-def flash guard and a step-rate cap on integer targets. Leave out present, retire and range(); the kit's dormant routes already cover a molecule that has not landed yet. Fix the idOf cache inside the same change. The camera, material and transport rows stay in the shell's table, because the shell owns those dials.

Recommendation · B1, with B3's source port

Take B1's three entries, say, mount and prefs, over one closed table of rows. Put the table in a leaf module that INFORMATIONAL (rack.js:664) and the stage words (:702) both import, so the seat order stops mattering. Add B3's chem.stage(): one record from MOLECULES in place of seven member reads, and it carries the NAME. Keep the hand law plain: say is called only from a control's hand callback (onInput or onChange), never from a target's set. A modulated ORBITAL dial is then silent with no token and no flag. Leave out B2's per-window kinds and extra seats until a second seat is actually wanted.
