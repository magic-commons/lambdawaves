## Fixed
1. **TIMELINE · its own undo was unreachable** (timeline B1). The kit offers the timeline's undo/redo as rows named `undo` / `redo` when the host has no `history`; λWAVES already owns those ids, so the kit's rows were dropped and Ctrl+Z over a focused timeline undid a λWAVES edit while the clip stayed. Fix: two rows `timeline.undo` / `timeline.redo` (Mod+Z · Mod+Shift+Z, Mod+Y) with the timeline's own `when` (keysLive), which THE FOCUS LAW of `lab/key-table.js` hands the chord while the timeline's surface has the focus; `TRAVELS` lists them so an undo lends no name. `lab/shell/keys.js`. Proved with real keys: Ctrl+Z over the focused timeline removes the clip and leaves λWAVES' history; Ctrl+Shift+Z redoes; off the timeline Ctrl+Z is λWAVES' again.
2. **MODULATION · a routed knob's × did nothing with a real mouse and its RANGE dial vanished under the hand** (modulation B1). The TIMELINE CLIP hold guard in `lab/shell/keys.js` stripped `data-param` for one pointerdown on any part of a routed knob, and the kit's `focusAway` (document capture, earlier in order) then read no stamp and dropped the ring's badges. Fix: the guard acts only on the host knob's OWN dial body (`.k-dial` whose nearest `.k` is the stamped knob) and the left button — what the kit's hold itself reads; the badges (×, the RANGE knob, which is a knob of its own inside the host) keep the stamp. Proved with real input: × removes the route; the RANGE badge stays shown mid-drag; a 700 ms hold on a routed dial still opens the ring, not TIMELINE CLIP.
3. **MODULATION · a hand on a routed `chem.*` / `reg.*` dial was overwritten and not saved** (modulation B2). Those dials never asked `modHand(id, v)` first, unlike every other routed dial. Fix: `api.modHand` handed into `createChem` and `createRegister` (`lab/windows/molecules.js`); κ and SPEED (`lab/chemview.js`) and A ↔ B, ω, E₀, the lane |b|² faders and phase knobs (`lab/statesview.js`, `hand()` / `slotId()`) start with the hand law. This is the road the ORBITAL dial and the ORBITAL register's A ↔ B take when they become targets.
4. **`__LW.mod.unroute()` left the target at its modulated value** (modulation B3, API only). Fix: when the last route leaves a target the registry restores its base, as the kit's own remove does (`lab/shell/facade.js`).
5. **A share link turned position space into `'r'`** (files B1). `lab/statelink.js` decoded the space bit as `'r'` while the app's position space is `'x'`, so after a link opened the domain overlays (KEPLER ORBIT, VORTEX…) were gated off even when switched on, and a save afterwards wrote `"space":"r"` into the project. Fix: decode to `'x'`; `lab/shell/persist.js` reads an old project's `'r'` as `'x'`; the statelink node suite's fixture said `'r'` too and now says `'x'`.
6. **A share link silently dropped the overlays** (files B2). The link's v1 record does not carry KEPLER ORBIT, VORTEX, PARTICLES or the DIALS, and the "THIS LINK DOES NOT CARRY" sentence named only the MOLECULE panel, the MODULATION rack and the rates. Fix: `encodeState` lists each overlay that is ON (`lab/statelink.js`) and `lab/shell/links.js` names them.

**Not fixed — the kit's** (files B3): SAVE AS ZIP… with a FOLDERS tile selected and the button pressed by keyboard names the zip after the tile but zips the live project (`lab/mir/folders/folders.js`, `zip.js`); a mouse press deselects the tile first, so only keyboard users meet it. An upstream MIR item (never edit `lab/mir/**`).
