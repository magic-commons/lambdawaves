## The record and how `nlm` is packed
The packer (`field.js:790`) writes `buf[o..o+3] = T.n, T.l, T.am, T.m` → `nlm`, `buf[o+7] = T.expo ?? T.n + 1` → `c.w`, `lag[0..5]` → `lag0`/`lag1.xy`,
`leg[0..5]` → `leg0`/`leg1.xy`. So the Cartesian table rides those seats with **no packer edit**:
`{ n: n_x, l: n_y, am: n_z, m: 0, norm, expo: 0, lag: [√ω_x, √ω_y, √ω_z, 0, 0, 0], leg: [1, 0, 0, 0, 0, 0], space: 'separable' }` →
`nlm = (n_x, n_y, n_z, 0)`, `c = (re, im, norm, 0)` (`c.w` = the form, 0 the oscillator), `lag0 = (a_x, a_y, a_z, 0)`. An unused slot is the same shape with
norm 0. norm = ∏(ωᵢ/π)^{1/4}/√(2^{nᵢ} nᵢ!).

## Where D and the azimuthal phase are formed; how the branch avoids the spherical pieces
`D` (the Legendre polynomial in cos θ) is formed **before** the branches, l.86, and multiplied **inside** each spherical branch (with `ipow(st, am)`). The
space-7 branch never multiplies `D`, `ipow(st, am)` or `ipow(r, l)`, so `leg = [1, 0…]` is cosmetic. The azimuthal phase `e^{imφ}` is applied **after** the
branches (l.136, `mm = select(m, 0.0, P.space == 4u)`): the brief asked to extend that `select`, which would have changed an existing line; instead the record
carries `m = 0` (`nlm.w = 0`), so `mm = 0` and the phase is exactly (1, 0) — the line stays byte-identical. The derived shaders (EQ's fold, `split('P.space')
.join('0u')`) see the new branch as `0u == 7u`, dead code, and none of their `once` anchors is inside the inserted text.
